# Oasis – Espelho da obra

Página somente leitura com o acompanhamento da Obra Oasis (resumo, prédio, cronograma, diário e semana).
Os dados vêm do app de acompanhamento e são atualizados automaticamente por uma tarefa agendada,
que grava as alterações em `data.json` (ver `sync/merge.py`).

Não edite `data.json` à mão: a próxima sincronização considera o que está nele como base.
